eval_f_cached

private subroutine eval_f_cached(me, x, f)

the (scaled) objective . The underlying value is reused from one of the last few evaluations if x is exactly (bitwise) the same point -- the solver evaluates f at each trial point of a line search and then again at the start of the next major iteration, at the accepted point, so this saves one call per major iteration. NaN if the user function failed (status /= 0).
