solver_name

private function solver_name(me, n) result(name)

the name of the QP solver that solved the last QP with n variables, for the printed output: mode_name, except that with sqpopt_qp_daqp, a QP that DAQP didn't solve (a fallback, or a forced elastic re-solve) was solved by the dense QP solver.

    function solver_name(me, n) result(name)

    class(sqpopt_qp_solver_type), intent(in) :: me
    integer,                      intent(in) :: n !! number of variables
    character(len=:), allocatable :: name

    if (resolved_mode(me, n) == sqpopt_qp_daqp .and. .not. me%daqp_used) then
        name = 'dense QP'
    else
        name = me%mode_name(n)
    end if

    end function solver_name
