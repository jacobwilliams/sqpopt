set_derivative_accuracy

private subroutine set_derivative_accuracy(me, accuracy)

set the accuracy the user's gjac is asked for (sqpopt_derivatives_fast or sqpopt_derivatives_accurate). A change empties the gjac cache, so that derivatives at a point already evaluated are evaluated again, at the new accuracy.
