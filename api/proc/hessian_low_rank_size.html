hessian_low_rank_size

private function hessian_low_rank_size(me) result(r)

the rank r of the low-rank part of the compact representation (see the module documentation): 2k (BFGS) or k (SR1) for k stored pairs. It is 0 when the matrix is just (no pairs yet, or a singular middle matrix, where hessian_vector_product falls back on that too), and in exact mode.

    integer function hessian_low_rank_size(me) result(r)

    class(sqpopt_hessian_type), intent(inout) :: me

    r = 0
    if (me%exact .or. me%n_history == 0) return
    if (.not. me%mid_valid) call factor_middle_matrix(me)
    if (.not. me%mid_ok) return
    r = merge(me%n_history, 2*me%n_history, me%use_sr1)

    end function hessian_low_rank_size
