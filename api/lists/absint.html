sqpopt_fc_func sqpopt_problem_module

evaluates the objective function and the nonlinear constraint vector

sqpopt_gjac_func sqpopt_problem_module

evaluates the gradient of the objective function and the nonzero values of the Jacobian of the constraint vector, , ordered to match the sparsity pattern set by set_jacobian_sparsity. accuracy says how accurate they need to be: functions with a cheaper, less accurate way of computing them (e.g. forward instead of central differences) may use it while accuracy=sqpopt_derivatives_fast; others can ignore it.
sqpopt_hessian_func sqpopt_problem_module

evaluates the nonzero values of the Hessian of the Lagrangian: , ordered to match the sparsity pattern set by set_hessian_sparsity.
sqpopt_ls_constraint_func sqpopt_linesearch_module

evaluates the (scaled) constraints at x (NaN if they can't be evaluated)
sqpopt_ls_objective_func sqpopt_linesearch_module

evaluates the (scaled) objective at x (NaN if it can't be evaluated)
sqpopt_report_func sqpopt_types_module

user-supplied callback invoked once per major SQP iteration for progress monitoring (see sqpopt_type%initialize's report argument). Set user_stop=.true. to have the solver stop after the current iteration (istat=sqpopt_user_requested_stop). The values are for the original (unscaled) problem.
sqpopt_residual_func sqpopt_nlls_module

evaluates the residuals and the constraints

sqpopt_residual_jac_func sqpopt_nlls_module

evaluates the nonzero values of the Jacobians of the residuals and of the constraints, each in the order of its sparsity pattern
sqpopt_soc_func sqpopt_linesearch_module

computes the second-order-corrected version p_soc of a rejected trial step p, given the constraint values c_trial at x+p (see sqpopt_soc_module); ok is false if no usable correction is available
start_interface sqpopt_sparse_ldl_module

start the backend for symmetric matrices of order n with the sparsity pattern irow/icol (each entry stands for itself and, off the diagonal, its mirror image; entries given more than once are added together). ok is false if it couldn't be started.
