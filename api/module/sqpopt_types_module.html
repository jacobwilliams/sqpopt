Common types and status codes used throughout sqpopt. Sparse matrices are always stored in coordinate (COO) format with 1-based indices -- the same convention used by the lusol and LSQR dependencies -- so that they may be passed to those solvers without conversion.

  • public subroutine sqpopt_report_func(iter, x, f, c, lambda, user_stop, data)

    user-supplied callback invoked once per major SQP iteration for progress monitoring (see sqpopt_type%initialize's report argument). Set user_stop=.true. to have the solver stop after the current iteration (istat=sqpopt_user_requested_stop). The values are for the original (unscaled) problem.

    Arguments

    major iteration number (starts at 1)

    current optimization variables dimension(n)
    real(kind=wp), intent(in) :: f

    current objective function value
    real(kind=wp), intent(in), dimension(:) :: c

    current constraint values dimension(m)
    real(kind=wp), intent(in), dimension(:) :: lambda

    current Lagrange multiplier estimate dimension(m)
    logical, intent(out) :: user_stop

    set .true. to request the solver stop
    class(*), intent(inout), optional :: data

    the user data given to set_functions

type, public ::  sqpopt_diagnosis_type

the diagnostics of a solve (see options%diagnostic_level): which constraints and variables are responsible for the errors at the final point, what the active set looks like there, and, from level 2, what the history of the iterations and the starting point say. Values are for the original (unscaled) problem. Everything here is also in the text of report and problem_report, which is what the solver prints.
