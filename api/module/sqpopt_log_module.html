log_put

The detailed log (options%print_level >= 3): the components that print details of their work (the line search and the trust region) each hold a sqpopt_log_type, set from options%print_level and options%output_unit at the start of each solve (so separate solver objects log independently). Also the number formatting shared by the log lines.
